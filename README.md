#  FunQuest

> **Play. Challenge. Win.**

FunQuest is a fun and interactive browser-based gaming platform featuring three classic games — **Tic Tac Toe, Rock Paper Scissors, and Sudoku**.

The project is built entirely with **HTML, CSS, and Vanilla JavaScript**, with a modern dark neon/glassmorphism interface designed to provide a smooth and engaging gaming experience.

---

##  Features

-  **Tic Tac Toe**
  - Two-player local gameplay
  - Turn tracking
  - Win and draw detection
  - Game reset functionality

-  **Rock Paper Scissors**
  - Play against the computer
  - Random computer choices
  - Score tracking
  - Win, lose, and draw results
  - Reset functionality

-  **Sudoku**
  - Dynamically generated Sudoku puzzles
  - Easy, Medium, and Hard difficulty levels
  - Timer
  - Mistake tracking
  - Hint system
  - Number pad
  - Keyboard input
  - Puzzle reset and new puzzle options

-  **Modern UI**
  - Dark neon gaming theme
  - Glassmorphism-inspired design
  - Responsive layout
  - Smooth hover effects and animations
  - Mobile-friendly interface
  - Google Fonts and Font Awesome icons
